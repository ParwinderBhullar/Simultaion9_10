# Simulation 9_10 – Order Intelligence Modernization

This repository contains my SQL Server modernization work for Simulation 9 using AdventureWorks2022.

## Files Included
- **01_schema_setup.sql** – Creates schema and working tables  
- **02_legacy_cursor_logic.sql** – Legacy nested cursor processing  
- **03_modernized_logic.sql** – Set-based modern implementation  
- **04_index_strategy.sql** – Indexes for performance optimization  
- **05_performance_testing.sql** – STATISTICS IO/TIME comparison  
- **06_diagnostics_and_comparison.sql** – Validation and diagnostics  
- **07_cleanup.sql** – Cleanup script    
- **/Modernization_Report.pdf** – Final report document

## Summary
This simulation rebuilds the legacy Order Intelligence module and modernizes it using set-based logic and index tuning to improve performance, scalability, and maintainability.
